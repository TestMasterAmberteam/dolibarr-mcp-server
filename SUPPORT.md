# Support

## Bug reports

Use the bug-report issue form with a minimal reproduction, expected and actual behavior, version,
platform, and sanitized logs. Never include a Dolibarr API key, Authorization header, internal URL,
or personal profile data.

## Usage questions

Use GitHub Discussions when enabled. Before asking, review the README, architecture, development,
and security documentation. Community help is best-effort and has no response SLA.

## Feature requests

Use the feature-request issue form. Describe the user outcome and security implications. Changes to
authentication, credential handling, or tenancy normally require an ADR before implementation.

## Security reports

Do not use issues or Discussions. Follow [SECURITY.md](SECURITY.md) and submit a private GitHub
security advisory.
